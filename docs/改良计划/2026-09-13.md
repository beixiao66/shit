## 四、缺陷修复

| 缺陷 | 根因 | 修复 |
|---|---|---|
| 数据看板「近 7 日营收趋势」从未显示 | `data.value` 赋值后同步调 `renderChart()`，此时 `v-if` 内的图表容器尚未挂载，`$chart` 为 null 直接 return —— ECharts 从未初始化 | 补 `await nextTick()`；同时把趋势补零为连续 7 个自然日、无数据时给出口径提示；日报窗口由「7×24 小时」对齐为自然日 |
| 提现记录 / 商家审核 / 退款处理 / 员工管理的分页器不显示 | merchant、user、pay 三服务缺 MyBatis-Plus 分页插件，`selectPage` 不生效且 total 恒为 0 | 三服务补齐 `MybatisPlusConfig`（与 order/product 一致） |
