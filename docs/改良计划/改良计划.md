## 二、待改良问题清单（按优先级）

### P0 —— 功能空档（用户可感知的"半成品"）

1. **商品详情页"加入购物车"未接线**
   - 位置：`mall-frontend/src/views/mall/ProductDetail.vue:49-56`
   - 现状：只弹提示 `已选规格：... —— 购物车功能在里程碑 5 接入`
   - 修正：游客 → 写入 localStorage 游客车（复用 CartPage 的 `mall_guest_cart` 结构）；登录用户 → 调 `api/cart.ts` 已有的 `addToCart(skuId, count)`，成功提示 + 顶部购物车角标更新
   - 卡点：样式类 `.spec_active` 判定（`specJson.includes(v)`）在多规格存在跨值匹配误选中，顺带改为精确匹配

2. **前台登录后无"退出登录"**
   - 位置：`Home.vue` 导航区（模板 66-76）
   - 修正：登录态下拉（头像/昵称 + 个人中心 + 我的订单 + 工作台[仅 type 1/2] + 退出登录），`stores/user.ts` 已有 `logout()` 直接用
   - 同时删除普通用户不该看到的"工作台"链接（或仅 type 1/2 渲染）

3. **注册页角色入口不直观**
   - 位置：`Register.vue` + `Home.vue` 导航"注册"链接
   - 修正：注册页顶部加"普通用户 / 商家入驻" tab（切换不影响已填表单），首页导航保留两个入口或下拉区分

4. **CartPage 规格列残句**
   - 位置：`CartPage.vue:170` `{{ row.specJson || '『规格' }}` —— 不完整文字，应显示已解析的规格文本或"单规格"

### P1 —— 数据与图片资源

5. **商品/广告图片资源缺失**
   - `public/img/` 不存在；`init.sql` 的 `main_img`、`img_url` 全是指向 `/img/...` 的假路径

   - 商品 3 / SKU 5 / 类目 5 / 广告 2 / 商家 2 —— 首页只有 3 张卡片
   - 修正：扩充到 12-16 个商品（每商家 2-3 类目覆盖）、每商品 2-6 SKU、广告 4 条、类目补后缀子类目，保证"类目走廊 + 广告条 + 推荐流"满铺

### P2 —— 视觉重构（对标淘宝）

7. **商城前台"购物形态"重构**（详见第三节设计规范）

   - 目标：一眼"这是电商",转化路径 首页→详情→加购→购物车→下单 每步有醒目 CTA

## 三、前台视觉重构设计规范（对标淘宝）

> 采用 frontend-design 流程产出：先定方向 → token 系统 → 页面布局 → 签名元素。

### 3.1 设计方向

**"橙红货架"** —— 从"纸面票据"转向"中国电商大盘"的通用认知：**白底 + 橙红主色 + 高密度商品网格 + 价格红色加粗**。保留 Mall-X 的品牌唯一性在于**红章价签**（商品卡右下角 MX 圆章，微渐变橙红），让"多商家价签"概念融入现代电商形态，而不是一套模板化的淘宝复制品。

### 3.2 Token 系统（替换 tokens.css 中"午夜蓝/琥珀金"）

| Token | 值 | 用途 |
|---|---|---|
| 品牌红 `--mx-primary` | `#FF5000` | 主 CTA、价格数字、Logo、链接 hover |
| 红深 `--mx-red-deep` | `#E23E00` | hover/按压态、角标 |
| 墨色 `--mx-ink` | `#1D2129` | 标题、正文 |
| 次灰 `--mx-ink-2` | `#6B7280` | 副文本、标签 |
| 底白 `--mx-bg` | `#FFFFFF` | 页面底 |
| 灰底 `--mx-bg-2` | `#F5F6F7` | 卡片底、分区底 |
| 提示黄 `--mx-warn` | `#FFB800` | 促销标签、限时 |
| 成功绿 `--mx-ok` | `#00B578` | 库存充裕、状态点 |

### 3.3 字体

- 显示/标题：`PingFang SC` / `Microsoft YaHei UI` 700，替代 mono 票据数字（价格保留 `font-variant-numeric: tabular-nums` 对齐）
- mono 仅保留于"订单号/单号"等数据场景（`--mx-mono`: `ui-monospace`），其余全部回归中文黑体栈

### 3.4 页面布局（ASCII 草图）

- 轮播播放进度点 + 卡片 hover 上浮 2px + 阴影加深（保留现有交互习惯）
