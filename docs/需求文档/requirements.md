# Mall-X 需求规格说明书（概览版）

> 依据《行业工程实践》教学大纲任务 1（需求分析、项目拆解）输出。完整用例文档/Demo 桥接见 CLAUDE.md 角色功能清单。

## 1. 项目背景

多商家入驻高并发电商平台"商城 Mall-X"：覆盖用户下单、支付创建、渠道回调、订单状态同步、物流发货、用户确认收货的电商全业务链路；前端 Web 双端（商城前台 + 管理后台），后端 Spring Boot 3 + Spring Cloud Alibaba 微服务。

## 2. 角色与账号体系（三元身份）

| 角色 | 登录入口 | 职责 |
|---|---|---|
| 游客 | 商城前台 | 浏览、搜索、游客购物车（localStorage） |
| 普通用户 | 商城前台 | 注册下单、支付、退款申请、确认收货、个人中心 |
| 商家 | 管理后台 | 入驻申请、店铺与商品管理、提现、店铺订单发货 |
| 平台管理员 | 管理后台 | 商家入驻审核、类目/广告管理、员工管理、订单管理、退款处理、提现审核、统计报表 |

## 3. 功能需求

### 商城前台
- 首页：轮播广告、服务保障、热销推荐、分类走廊、商品网格（目录式）
- 商品：列表（分类筛选/关键字搜索/分页，搜索同时匹配商品名与店铺名，命中店铺可直接进店）、详情（SKU 规格选择 + "猜你喜欢"同类推荐）
- 购物车：游客本地 + 登录自动合并；勾选结算
- 订单：下单（跨店拆单）、取消、支付（沙箱/Mock 渠道）、确认收货、物流查看、申请退款
- 个人中心：资料、收货地址（多地址/默认）

### 商家端（后台，type=2 菜单）
- 入驻申请（提交后管理员审核，审核通过方可登录）
- 店铺设置（名称/logo/介绍/地址）、商品管理（含 SKU 规格行编辑、上下架）
- 店铺订单（查看/发货，写物流公司与运单号）
- 提现申请（余额校验：申请减、驳回加）与记录

### 平台管理端（后台，type=1 菜单）
- 数据看板：营收/进账/出账/入驻（图表可视化），统计报表（进出账流水、入驻统计）
- 类目管理（两级、删除校验无在售商品）、广告位管理
- 商家入驻审核（通过/驳回+原因）、提现处理（打款成功/驳回+回补余额）、退款记录
- 订单管理（全局查看/代发货）、员工管理（创建/启用/禁用）

## 4. 非功能需求（架构约束）

| 项 | 要求 | 落地说明 |
|---|---|---|
| 高并发 QPS ≥ 1000 | 架构设计目标 | 网关限流 + Redis Lua 库存挡板 + 无状态服务水平扩展；压测参见大纲任务 15（联调阶段执行） |
| 高可用 99% | 架构设计目标 | 微服务治理（限流/熔断降级占位）、Nacos 注册发现 |
| 幂等安全 | 关键写入 | 下单请求键、支付回调（锁+唯一索引+状态机）、退款 out_request_no、消息消费状态机校验 |
| 数据一致性 | 单库演示 | 库存（Redis 预扣+DB 条件扣）、订单状态机条件更新、商家余额（事件式入账/扣回） |
| 性能 | 报表 | 聚合走 idx_create_time；商品展示价动态 MIN(sku.price) 无冗余 |

## 5. 验收要点（对照大纲任务 1-18）

需求/数据库/概要/接口文档 + 可运行演示（Web 双端全链路）+ 超时取消（延迟消息）+ 支付回调幂等 + 库存原子扣减 + 容器化部署。
